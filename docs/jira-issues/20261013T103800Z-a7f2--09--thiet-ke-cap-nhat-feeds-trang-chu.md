# [MyVNPT] Thiết kế cập nhật Feeds trang chủ

## Mục tiêu
Cập nhật và tối ưu giao diện Feeds trang chủ theo phản hồi và yêu cầu mới.

## Phạm vi công việc
- Điều chỉnh bố cục card feeds, kích thước thumbnail và mật độ thông tin theo yêu cầu mới.
- Bổ sung các trạng thái tương tác like/share/chuyển tiếp bài viết.
- Cập nhật file Figma và thông báo các thay đổi cho BA/FE.
