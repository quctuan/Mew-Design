# [MyVNPT] Thiết kế UI/UX Các Widgets trang chủ

## Mục tiêu
Xây dựng bộ thư viện widget tiện ích hiển thị trên trang chủ MyVNPT.

## Phạm vi công việc
- Thiết kế các loại widget tiện ích: tra cứu tài khoản, nạp tiền nhanh, dung lượng data, thông báo nóng.
- Chuẩn hóa kích thước, tỷ lệ lưới, bo góc và Design Tokens cho hệ thống widget.
- Bàn giao component library và specs tương tác cho đội ngũ phát triển FE.

## Đầu ra và tiêu chí hoàn thành
- File thiết kế Figma hoàn chỉnh: [Widgets](https://www.figma.com/design/zlEC3PlD37tAJLFbdUGCnm/Homepage?node-id=37078-92224&t=2l4NdawFuEmcQ4ue-9)
- Issue liên quan/Issue mẹ: GMYVNPT1-11
- Đầy đủ các màn hình, trạng thái tương tác và component specs được bàn giao, làm rõ với đội ngũ BA và Dev.
