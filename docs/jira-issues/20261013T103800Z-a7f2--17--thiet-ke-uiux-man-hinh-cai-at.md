# [MyVNPT] Thiết kế UI/UX Màn hình Cài đặt

## Mục tiêu
Thiết kế giao diện cài đặt hệ thống (ngôn ngữ, bảo mật sinh trắc học, liên kết tài khoản) trên MyVNPT.

## Phạm vi công việc
- Thiết kế danh mục các tùy chọn cài đặt hệ thống ứng dụng MyVNPT.
- Thiết kế tương tác bật/tắt xác thực sinh trắc học (FaceID/Vân tay), đổi mật khẩu và quản lý phiên đăng nhập.
- Bàn giao specs layout Figma cho BA và FE.

## Đầu ra và tiêu chí hoàn thành
- File thiết kế Figma hoàn chỉnh: [Cài đặt](https://www.figma.com/design/zlEC3PlD37tAJLFbdUGCnm/Homepage?node-id=11398-180644&t=bMqbC0VKfTCbJQsp-19)
- Issue liên quan/Issue mẹ: GMYVNPT1-181
- Đầy đủ các màn hình, trạng thái tương tác và component specs được bàn giao, làm rõ với đội ngũ BA và Dev.
