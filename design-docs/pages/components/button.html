Button

Hiển thị một nút bấm hoặc một thành phần có giao diện như nút bấm để kích hoạt hành động.

iOS (Swift) 
import MyVNPTDesignSystem

DSButton(text: "Button", style: .primary, size: .md)
Android (Kotlin) 
import vn.myvnpt.designsystem.components.DSButton
import vn.myvnpt.designsystem.components.ButtonStyle

DSButton(
    text = "Button",
    style = ButtonStyle.Primary
)

Examples / Variants

Primary

Nút bấm có độ nhấn mạnh cao mặc định cho các hành động chính.

iOS (Swift) 
DSButton(text: "Label", style: .primary)
Android (Kotlin) 
DSButton(text = "Label", style = ButtonStyle.Primary)

Secondary

Dành cho các hành động phụ có độ ưu tiên trung bình. Có đường viền và chữ theo màu thương hiệu.

iOS (Swift) 
DSButton(text: "Label", style: .secondary)
Android (Kotlin) 
DSButton(text = "Label", style = ButtonStyle.Secondary)

Tertiary

Biến thể có độ nhấn mạnh thấp, không có đường viền hay hình nền, giữ nguyên màu chữ của thương hiệu.

iOS (Swift) 
DSButton(text: "Label", style: .tertiary)
Android (Kotlin) 
DSButton(text = "Label", style = ButtonStyle.Tertiary)

Text

Ghost-like button using neutral text color instead of brand.

iOS (Swift) 
DSButton(text: "Label", style: .ghost)
Android (Kotlin) 
DSButton(text = "Label", style = ButtonStyle.Ghost)

Underline

Nút bấm dạng chữ inline kèm đường gạch chân, biểu thị cấu trúc của Link.

iOS (Swift) 
DSButton(text: "Label", style: .link)
Android (Kotlin) 
DSButton(text = "Label", style = ButtonStyle.Link)

With Icon

Add btn-icon-left or btn-icon-right to correctly space an inline SVG.

iOS (Swift) 
// Icon Left
DSButton(text: "Label", style: .primary, leftIcon: UIImage(named: "ic_check"))

// Icon Right
DSButton(text: "Label", style: .primary, rightIcon: UIImage(named: "ic_check"))
Android (Kotlin) 
// Icon Left
DSButton(text = "Label", style = ButtonStyle.Primary, leftIcon = R.drawable.ic_check)

// Icon Right
DSButton(text = "Label", style = ButtonStyle.Primary, rightIcon = R.drawable.ic_check)

Icon Only

Use btn-icon-only for an evenly-padded square action button, ensuring an aria-label is provided.

iOS (Swift) 
DSButton(
    style: .secondary,
    size: .sm,
    leftIcon: UIImage(named: "ic_settings"),
    isIconOnly: true
)
Android (Kotlin) 
DSButton(
    style = ButtonStyle.Secondary,
    size = ButtonSize.Sm,
    leftIcon = R.drawable.ic_settings,
    isIconOnly = true
)

.btn-md Height / Padding / Font 40px / 16px horizontal / 16px text

.btn Border Radius var(--br-full) / 9999px
Icon & Text Spacing (Gap) var(--space-1x) / 4px

API Reference

Props

Class / Prop Type Default Description
variant primary | secondary | tertiary | ghost | link primary Determines button Hierarchy (Primary, Secondary, Tertiary, Text, Underline).
size sm | md | lg md Controls button sizes reflecting exact Figma component variants.
btn-icon-left | btn-icon-right | btn-icon-only modifier class none Adds margin when an icon SVG is used inside the button.
btn-full modifier class false Stretches button width: 100%.
