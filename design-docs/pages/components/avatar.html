Avatar

Thành phần hình ảnh có tính năng dự phòng dùng để đại diện cho người dùng hoặc một thực thể.

iOS (Swift) 
import MyVNPTDesignSystem

DSAvatar(
    imageURL: URL(string: "https://..."),
    size: .md,
    shape: .circle
)
Android (Kotlin) 
import vn.myvnpt.designsystem.components.DSAvatar
import vn.myvnpt.designsystem.components.AvatarSize
import vn.myvnpt.designsystem.components.AvatarShape

DSAvatar(
    imageUrl = "https://...",
    size = AvatarSize.Md,
    shape = AvatarShape.Circle
)

Examples / Variants

Image & Fallback

Avatar hỗ trợ hiển thị hình ảnh, ký tự viết tắt, và biểu tượng dự phòng.

VQ
iOS (Swift) 
// Image Avatar
DSAvatar(imageURL: URL(string: "..."), size: .md)

// Initials Fallback
DSAvatar(fallbackString: "VQ", size: .md)

// Icon Fallback
DSAvatar(fallbackIcon: UIImage(named: "ic_user"), size: .md)
Android (Kotlin) 
// Image Avatar
DSAvatar(imageUrl = "...", size = AvatarSize.Md)

// Initials Fallback
DSAvatar(fallbackString = "VQ", size = AvatarSize.Md)

// Icon Fallback
DSAvatar(fallbackIcon = R.drawable.ic_user, size = AvatarSize.Md)

Sizes & Status

Avatars can be sized from sm to xl, and incorporate status indicators.

A
iOS (Swift) 
// Small with Online Status
DSAvatar(imageURL: URL(string: "..."), size: .sm, status: .online)

// Medium with Away Status
DSAvatar(imageURL: URL(string: "..."), size: .md, status: .away)

// Large with Busy Status
DSAvatar(imageURL: URL(string: "..."), size: .lg, status: .busy)

// Extra Large Fallback with Offline Status
DSAvatar(fallbackString: "A", size: .xl, status: .offline)
Android (Kotlin) 
// Small with Online Status
DSAvatar(imageUrl = "...", size = AvatarSize.Sm, status = AvatarStatus.Online)

// Medium with Away Status
DSAvatar(imageUrl = "...", size = AvatarSize.Md, status = AvatarStatus.Away)

// Large with Busy Status
DSAvatar(imageUrl = "...", size = AvatarSize.Lg, status = AvatarStatus.Busy)

// Extra Large Fallback with Offline Status
DSAvatar(fallbackString = "A", size = AvatarSize.Xl, status = AvatarStatus.Offline)

Shapes

Avatar có thể hiển thị dưới dạng hình tròn khối hoặc hình vuông bo góc nhẹ.

iOS (Swift) 
// Circle Shape (Default)
DSAvatar(imageURL: URL(string: "..."), size: .lg, shape: .circle)

// Rounded Square Shape
DSAvatar(imageURL: URL(string: "..."), size: .lg, shape: .rounded)
Android (Kotlin) 
// Circle Shape (Default)
DSAvatar(imageUrl = "...", size = AvatarSize.Lg, shape = AvatarShape.Circle)

// Rounded Square Shape
DSAvatar(imageUrl = "...", size = AvatarSize.Lg, shape = AvatarShape.Rounded)

Design Specifications

Element Property Token / Value
.avatar-sm Width & Height 24px
.avatar-md Width & Height 32px
.avatar-lg Width & Height 40px
.avatar-xl Width & Height 56px
.avatar-circle Border Radius var(--br-full) / 9999px
.avatar-status Size 30% of Avatar's Dimensions

API Reference

Props

Class Type Default Description
size class sm | md | lg | xl md Defines the square dimension of the avatar element.
shape class circle | rounded - Determines border radius. circle sets a full curve (9999px), rounded sets an 8px curve.
.avatar-status component - Small indicator circle placed at the bottom-right corner. Paired with status-[color].
status class online | busy | away | offline - Modifies the background color of the .avatar-status component.
