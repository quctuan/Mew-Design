Checkbox & Radio Option

Bộ components cho phép người dùng chọn một hoặc nhiều lựa chọn. Bao gồm Checkbox (cho phép chọn nhiều) và Radio (chỉ cho phép chọn một).

Hero Preview

iOS (Swift)
import MyVNPTDesignSystem

// Checkbox Option
DSCheckboxOption(
    label: "Checkbox Option",
    layout: .left, // checkbox nằm bên trái
    isChecked: $isChecked
)

// Radio Option
DSRadioOption(
    label: "Radio Option",
    type: .shortContent, // Label + radio
    isSelected: $isSelected
)
Android (Kotlin)
import vn.myvnpt.designsystem.components.DSCheckboxOption
import vn.myvnpt.designsystem.components.DSRadioOption

// Checkbox Option
DSCheckboxOption(
    label = "Checkbox Option",
    layout = CheckboxLayout.LEFT,
    isChecked = isChecked,
    onCheckedChange = { ... }
)

// Radio Option
DSRadioOption(
    label = "Radio Option",
    type = RadioOptionType.SHORT_CONTENT,
    isSelected = isSelected,
    onSelectedChange = { ... }
)

Usage Guidelines

  • Do: Sử dụng Checkbox khi người dùng có thể chọn multiple options (từ 0 đến nhiều).
  • Do: Sử dụng Radio khi người dùng bắt buộc chỉ được chọn duy nhất 1 option trong bộ.
  • Do: Ưu tiên đặt Checkbox/Radio Option theo chiều dọc (list) để dễ dàng thao tác trên mobile.
  • Don't: Không dùng Checkbox cho các thiết lập có tính chất 'hoạt động ngay lập tức' như bật/tắt Wi-Fi (trường hợp đó nên dùng Toggle).
  • Don't: Đừng yêu cầu User phải tốn quá nhiều sức mới click trúng ô checkbox, hãy cho phép toàn bộ vùng Label + khoảng trắng xung quanh (touch area) đều trigger thao tác nhấn.

Accessibility

  • Sử dụng thuộc tính kiểm soát chuẩn role="checkbox" / role="radio" cùng aria-checked nếu không sử dụng thẻ native.
  • Sử dụng bộ thẻ <fieldset> và <legend> để gom nhóm các Radio Button liên quan đến nhau theo semantic HTML/Screen reader.
  • Trạng thái Disabled phải gắn kèm aria-disabled="true" để thiết bị đọc có thể cảnh báo User thay vì chỉ mờ đi.
  • Hãy đảm bảo Label và thẻ Input input được liên kết cứng thông qua thuộc tính for / id.
  • Đảm bảo kích thước Touch Target (vùng thao tác tap) tối thiểu là 44x44 points.
