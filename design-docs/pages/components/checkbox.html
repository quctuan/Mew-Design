Usage

iOS (Swift) 
import MyVNPTDesignSystem

// Standard Checkbox
DSCheckbox(text: "Remember me", isChecked: $isChecked)

// Checkbox with Description
DSCheckbox(
    text: "Subscribe to newsletter",
    description: "Get daily updates directly to your inbox.",
    isChecked: $isChecked
)
Android (Kotlin) 
import vn.myvnpt.designsystem.components.DSCheckbox

// Standard Checkbox
DSCheckbox(
    text = "Remember me",
    isChecked = isChecked,
    onCheckedChange = { isChecked = it }
)

// Checkbox with Description
DSCheckbox(
    text = "Subscribe to newsletter",
    description = "Get daily updates directly to your inbox.",
    isChecked = isChecked,
    onCheckedChange = { isChecked = it }
)

Props Reference

Class / Target Type Default Description
checked boolean false Native browser property applied to the <input> element to toggle checked state. Shows the internal SVG checkmark path via CSS content.
disabled boolean false Native browser property applied to the <input> element. When true, prevents interaction and alters border/background fills to gray variants.
is-error modifier class false Applied to .checkbox-wrapper to highlight the checkbox outline and description text in Red to indicate mandatory interaction failures.

Accessibility Considerations

  • Input wraps logically inside the <label> element. Clicking the label text or description will natively trigger the underlying CSS-restyled checkbox.
  • Hidden visually for regular users, but remains identifiable to screen readers via appearance: none rather than display: none.
  • Exhibits a clear double-ring focus outline when navigated via Keyboard Tab, complying with WCAG 2.1 Focus Visible standards.
