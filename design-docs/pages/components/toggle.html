Usage

iOS (Swift) 
import MyVNPTDesignSystem

// Standard Toggle
DSToggle(
    title: "Push notifications",
    isOn: $pushEnabled
)

// Toggle with Description
DSToggle(
    title: "Automatic backup",
    description: "Saves your progress to the cloud every 10 minutes.",
    isOn: $backupEnabled
)
Android (Kotlin) 
import vn.myvnpt.designsystem.components.DSToggle

// Standard Toggle
DSToggle(
    title = "Push notifications",
    isChecked = pushEnabled,
    onCheckedChange = { pushEnabled = it }
)

// Toggle with Description
DSToggle(
    title = "Automatic backup",
    description = "Saves your progress to the cloud every 10 minutes.",
    isChecked = backupEnabled,
    onCheckedChange = { backupEnabled = it }
)

Props Reference

Class / Target Type Default Description
checked boolean false Native browser property on <input>. Toggles the switch track color and transforms the knob via CSS.
disabled boolean false Native browser property. Dims the track, removes the knob shadow, and prevents interaction.
toggle-sm modifier class false Applied to .toggle-wrapper to reduce the switch size from 44x24 to 32x18, along with corresponding font sizes.

Accessibility Considerations

  • Toggles act like instantaneous switches. Unlike checkboxes, their state change should ideally take effect immediately without requiring a "Save" button.
  • Built natively on top of <input type="checkbox"> wrapped in a <label>, ensuring 100% native keyboard Tab support and Spacebar toggling.
  • Focus states expand beyond the bounds of the pill track to ensure visibility across varying background constrasts.
