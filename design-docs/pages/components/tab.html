Quản lý cài đặt settings tài khoản và tùy chọn của bạn tại đây. Lưu ý rằng tab active có một đường viền gạch chân liền lạc theo màu thương hiệu.

Alerts

Cấu hình Push notification nhận tin.

iOS (Swift) 
import MyVNPTDesignSystem

// Standard Tabs (Line Style)
DSTabView(
    tabs: ["Account", "Password", "Notifications"],
    selectedIndex: $selectedIndex,
    style: .line
) { index in
    if index == 0 {
        AccountSettingsView()
    } else if index == 1 {
        PasswordSettingsView()
    }
}
Android (Kotlin) 
import vn.myvnpt.designsystem.components.DSTabs
import vn.myvnpt.designsystem.components.DSTabStyle

// Standard Tabs (Line Style)
DSTabs(
    tabs = listOf("Account", "Password", "Notifications"),
    selectedIndex = selectedIndex,
    onTabSelected = { selectedIndex = it },
    style = DSTabStyle.Line
)

// Content View
when (selectedIndex) {
    0 -> AccountSettingsView()
    1 -> PasswordSettingsView()
}

Examples / Variants

Tab có hai kiểu trực quan phân biệt tuỳ vào cấp độ của thông tin phân luồng và vị trí dùng trên giao diện.

Line Variant (Mặc định)

Sử dụng như điều hướng cấp 1 trong page. Dùng gạch chân dưới text để đánh dấu State=Active.

Pill Variant (Segmented Control)

Sử dụng như điều hướng cấp phụ nếu đã có Line Variant nằm ở trên nó. Nền pill đệm trọn vùng text cho State=Active trải nghiệm như Switcher.

Swift
DSTabView(..., style: .pill)

Usage Guidelines

  • Do: Đảm bảo văn bản trong Tab là cực kỳ ngắn (1-2 từ). Text dài phá vỡ cấu trúc ngang và thường mất chữ.
  • Do: Cố gắng duy trì từ 2-4 tab. Nếu vượt quá, cân nhắc làm layout lướt (Scrollable row) hoặc một Dropdown Picker (Lọc).
  • Do: Line Style thường ưu tiên Fill theo chiều ngang màn hình (Equally Spaced) để phủ đầy đặn trên thanh Top NavBar.
  • Don't: Đừng bao giờ đè nhiều thành phần Line Tab cấp tính xuống các mục dưới. Thay vào chắp vá bằng Pill Tab cho navigation cấp 2.

Accessibility

  • Semantic structure: Dùng tổ hợp HTML Attributes sau cùng lúc: `
    ` bao lấy `
  • State: Tab đang được trỏ chuột phải báo aria-selected="true", tab khác là "false". Đảm bảo screen reader đọc được "Tab 1 of X".
  • Keyboard Navigation: Hỗ trợ mũi tên Trái/Phải (Left/Right Arrow) luân chuyển qua lại giữa các tab thay vì chỉ Tap tab mới focus.
  • Tương phản màu trên Pill Active/Inactive phải đạt tỷ lệ 4.5:1.
