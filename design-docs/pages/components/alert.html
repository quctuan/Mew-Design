Alert

Dùng khi cần thông báo cho user về task họ cần làm mà không phải context của màn hình. Hiển thị thông tin quan trọng dưới dạng banner có icon và nội dung.

Đây là nội dung alert.
iOS (Swift) 
import MyVNPTDesignSystem

DSAlert(type: .positive, text: "Đây là nội dung alert.")
Android (Kotlin) 
import vn.myvnpt.designsystem.components.DSAlert
import vn.myvnpt.designsystem.components.AlertType

DSAlert(
    type = AlertType.Positive,
    text = "Đây là nội dung alert."
)

Usage Guidelines

  • Dùng khi cần thông báo cho user về task họ cần làm mà không phải context của màn hình.
  • Chỉ dùng Variant Multiple khi toàn bộ Alert có tác dụng như một button để mở chi tiết sự kiện.

Accessibility - a11y

  • Sử dụng role="alert" cho các thông báo quan trọng, role="status" cho thông tin bổ sung.
  • Icon phải có aria-hidden="true" vì thông tin đã được truyền đạt bằng text.
  • Contrast ratio: text #34404B trên nền #F4F4F4 đạt 7.2:1 (AA/AAA).
  • Variant Multiple (có chevron) phải là button hoặc <a> với label rõ ràng.
