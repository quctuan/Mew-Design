Deactivate Account

Bạn có chắc chắn muốn vô hiệu hóa tài khoản không? Tất cả dữ liệu của bạn sẽ bị xóa vĩnh viễn. Hành động này không thể hoàn tác.

iOS (Swift) 
import MyVNPTDesignSystem

// Show standard Modal/Dialog
DSModal.show(
    title: "Deactivate Account",
    message: "Bạn có chắc chắn muốn vô hiệu hóa tài khoản không? Tất cả dữ liệu sẽ bị xóa.",
    primaryButtonTitle: "Deactivate",
    primaryButtonAction: {
        // Handle deactivate
    },
    secondaryButtonTitle: "Cancel",
    secondaryButtonAction: {
        // Handle cancel
    }
)
Android (Kotlin) 
import vn.myvnpt.designsystem.components.DSModal

// Show standard Dialog
DSModal(
    title = "Deactivate Account",
    message = "Bạn có chắc chắn muốn vô hiệu hóa tài khoản không? Tất cả dữ liệu sẽ bị xóa.",
    primaryButtonText = "Deactivate",
    onPrimaryButtonClick = {
        // Handle deactivate
    },
    secondaryButtonText = "Cancel",
    onSecondaryButtonClick = {
        // Handle cancel
    },
    onDismissRequest = {
        // Handle dismiss
    }
)

Usage Guidelines

  • Do: Đảm bảo background đằng sau bị phủ lớp overlay tối (thường là rgba #000, 40-50%) để tập trung thị giác vào modal.
  • Do: Cung cấp tối thiểu 1 hành động đóng modal (ví dụ nút "Got it" hoặc icon `X` Close).
  • Don't: Không nhồi nhét quá nhiều Action phụ trong Footer. Tối đa chỉ nên có 2 (Primary và Secondary/Tertiary).
  • Don't: Đừng bao giờ stack (xếp chồng) Modal này lên Modal khác. Nếu cần flow phức tạp, hãy sử dụng Fullscreen Modal hoặc Bottomsheet để thay thế.

Accessibility

  • Sử dụng thuộc tính role="dialog" hoặc role="alertdialog" (với các cảnh báo mạnh).
  • Gán aria-labelledby="[id_tieu_de]" vào container modal để link tới Title, và aria-describedby="[id_mo_ta]" với mô tả nằm ở body.
  • Focus Trap: Khi modal mở, tiêu cự bàn phím (focus) không thể lọt ra bên ngoài modal. Khi đóng, trả focus về nút đã mở modal.
  • Hỗ trợ phím ESC để thoát nếu modal đó không thuộc loại bắt buộc phản hồi (Action required).
