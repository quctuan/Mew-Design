Flush Card (No shadow)

Sometimes you don't want a shadow, just a subtle border to contain content within a modal or a gray background area.

Usage

iOS (Swift) 
import MyVNPTDesignSystem

DSCard {
    // Header
    DSCardHeader(
        title: "Card Title",
        description: "Card description goes here."
    )
    
    // Content
    DSCardContent {
        Text("Main content of the card.")
    }
    
    // Footer
    DSCardFooter {
        DSButton(text: "Cancel", style: .secondary)
        DSButton(text: "Action", style: .primary)
    }
}
Android (Kotlin) 
import vn.myvnpt.designsystem.components.card.*
import vn.myvnpt.designsystem.components.button.*
import androidx.compose.material3.Text

DSCard {
    // Header
    DSCardHeader(
        title = "Card Title",
        description = "Card description goes here."
    )
    
    // Content
    DSCardContent {
        Text("Main content of the card.")
    }
    
    // Footer
    DSCardFooter {
        DSButton(text = "Cancel", style = ButtonStyle.Secondary)
        DSButton(text = "Action", style = ButtonStyle.Primary)
    }
}

Props Reference

Class Type Description
.card container The main wrapper of the card. Handles borders, radius, and shadows.
.card-header component Contains the title and description, implements flex layout with gap.
.card-content component The main body area. Expanding region (flex-grow: 1).
.card-footer component Footer area, aligns children to the right side by default.
.card-interactive modifier Adds a hover state that slightly elevates the card and increases shadow.
.card-flush modifier Removes the box-shadow, leaving only the border. Useful for nested cards.

Design Specifications

Element Property Token / Value
.card Border Radius var(--br-16x) / 16px
.card Shadow (Default) 0 4px 6px -1px rgba(0,0,0,0.05), ...
.card-header Padding 24px (Top, L, R), 16px (Bottom)
.card-content Padding 0px (Top), 24px (L, R, Bottom)
.card-footer Padding 16px (Top), 24px (L, R, Bottom)

Accessibility Considerations

  • Ensure semantic HTML flow inside .card (e.g., using <h3> for title).
  • If the entire card is clickable (e.g., .card-interactive), wrap it in an <a> tag or button, or manage focus and generic click events with javascript and tabindex.
