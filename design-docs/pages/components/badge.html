Badge

Một chỉ báo hình ảnh nhỏ gọn, không tương tác, dùng để làm nổi bật trạng thái, thuộc tính hoặc số lượng.

New Feature
iOS (Swift) 
import MyVNPTDesignSystem

DSBadge(text: "New Feature", style: .primary, size: .md)
Android (Kotlin) 
import vn.myvnpt.designsystem.components.DSBadge
import vn.myvnpt.designsystem.components.BadgeStyle

DSBadge(
    text = "New Feature",
    style = BadgeStyle.Primary
)

Examples / Variants

Color Variants

Badges come in different semantic colors to represent state.

Neutral Primary Success Warning Error
iOS (Swift) 
DSBadge(text: "Neutral", style: .neutral)
DSBadge(text: "Primary", style: .primary)
DSBadge(text: "Success", style: .success)
DSBadge(text: "Warning", style: .warning)
DSBadge(text: "Error", style: .error)
Android (Kotlin) 
DSBadge(text = "Neutral", style = BadgeStyle.Neutral)
DSBadge(text = "Primary", style = BadgeStyle.Primary)
DSBadge(text = "Success", style = BadgeStyle.Success)
DSBadge(text = "Warning", style = BadgeStyle.Warning)
DSBadge(text = "Error", style = BadgeStyle.Error)

With Icon (Pill)

You can embed an SVG icon on the left, right, or both sides.

Label Label
iOS (Swift) 
// Left Icon
DSBadge(text: "Label", style: .primary, leftIcon: UIImage(named: "ic_check"))

// Right Icon
DSBadge(text: "Label", style: .primary, rightIcon: UIImage(named: "ic_chevron"))
Android (Kotlin) 
// Left Icon
DSBadge(text = "Label", style = BadgeStyle.Primary, leftIcon = R.drawable.ic_check)

// Right Icon
DSBadge(text = "Label", style = BadgeStyle.Primary, rightIcon = R.drawable.ic_chevron)

Rounded Shape

Use the badge-round modifier to reduce the border radius (e.g. 8px).

Label Label
iOS (Swift) 
DSBadge(
    text: "Label",
    style: .success,
    shape: .rounded,
    leftIcon: UIImage(named: "ic_check")
)
Android (Kotlin) 
DSBadge(
    text = "Label",
    style = BadgeStyle.Success,
    shape = BadgeShape.Rounded,
    leftIcon = R.drawable.ic_check
)

Design Specifications

Element Property Token / Value
.badge-sm Height / Padding / Font 20px / 6px horizontal / 12px text
.badge-md Height / Padding / Font 24px / 8px horizontal / 14px text
.badge-lg Height / Padding / Font 28px / 12px horizontal / 14px text
.badge (Pill) Border Radius var(--br-full) / 9999px

API Reference

Props

Class Type Default Description
variant class neutral | primary | success | warning | error neutral Dictates the background, text, and border color based on semantic tokens.
size class sm | md | lg md Defines the height, padding, and font size.
shape class (none) | badge-round (none) - Pill Defines the border radius. Pill is fully rounded, Round is slightly rounded (8px).
icon classes badge-icon-left | badge-icon-right none Provides appropriate spacing for inline SVGs on the left or right side of the text.
