Badge

Preview

INTENT VARIANTS
Primary Secondary Success Error

Props

Name Type Default Description
variant "primary" | "secondary" | "success" | "error" "primary" Defines the semantic intent and color palette map.
children ReactNode - The text label content to render inside the badge.

Accessibility

  • Badges are intrinsically decorative display elements and omit tab-index mappings automatically.
  • Foreground labels fulfill WCAG AA contrast ratio when composed against the designated semantic background hues.

Usage

HTML 
<!-- Primary Variant -->
<span class="badge badge-primary">New Feature</span>

<!-- Error Variant -->
<span class="badge badge-error">Failed</span>
