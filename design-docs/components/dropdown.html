Props

Name Type Default Description
isOpen boolean false Reactively tracks if the internal listbox popover is visible.
multiple boolean false Instructs the selection logic to emit an array of values instead of a single string.
options Array<DropdownOption> [] The iterable array containing object labels, keys, and disabled statuses.

Accessibility

  • Triggers apply aria-expanded and aria-haspopup="listbox" to notify standard screen readers.
  • Custom Arrow key binding allows navigating role="option" children using keyboard up/down traversal.
  • Closing the menu guarantees that focus is explicitly returned back to the trigger node.

Usage

HTML 
<div class="dropdown-wrapper">
  <label class="dropdown-label">Language</label>
  <div class="dropdown-trigger" tabindex="0" aria-expanded="false">
    <span class="dropdown-value">English</span>
    <svg class="dropdown-icon" viewBox="0 0 24 24"><path d="M7 10l5 5 5-5z"/></svg>
  </div>
</div>
