Toggle (Switch)

Preview

STATES
DISABLED STATES

Props

Name Type Default Description
isOn boolean false Tracks whether the switch is activated or deactivated.
disabled boolean false Prevents state toggling via clicks or keyboard events.

Accessibility

  • Acts as a native checkbox input ensuring standard HTML form submission behavior.
  • Focus states trigger an expanded outline halo on the track rather than text.
  • Semantic <label> wrapping guarantees an expanded clickable hit-area for touch devices.

Usage

HTML 
<label class="toggle-wrapper">
  <input type="checkbox" class="toggle-input" id="wifi-settings">
  <div class="toggle-track">
    <div class="toggle-thumb"></div>
  </div>
  <span class="toggle-label">Enable Wi-Fi Sync</span>
</label>
