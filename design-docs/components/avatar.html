Props

Name Type Default Description
type "picture" | "initials" "picture" Fallback type if image loading fails.
src string undefined Image source URL. Required if type is "picture".
size "large" | "medium" | "small" "medium" Dimension mapping defining width, height, and font scale.

Accessibility

  • Picture avatars must provide a readable alt attribute describing the subject.
  • Initials must be placed within a span readable by Screen Readers if purely decorative, or appended with aria-label.

Usage

HTML 
<!-- Picture Type -->
<div class="avatar-container">
  <img class="avatar-img" src="/imgs/user.jpg" alt="Jane Doe">
</div>

<!-- Initials Fallback Type -->
<div class="avatar-container">
  <span class="avatar-initials">JD</span>
</div>
