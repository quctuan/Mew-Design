Props

Name Type Default Description
state "default" | "active" | "filled" | "disabled" "default" Controls interaction and visual state.
feedback "none" | "positive" | "destructive" "none" Sets validation colors (red/green) and icons.
iconLeft boolean / Node false Renders an icon inside the input on the left side.
trailingNode boolean / Node false Renders a string or button directly inside the right boundary.

Accessibility

  • Always associate a visible <label> with the input via the for / id attributes.
  • Use aria-invalid="true" when the input is in a Destructive/Error state.
  • If helper text describes an error, link it using aria-describedby on the input field.

Usage

HTML 
<div class="input-wrapper">
  <label for="email" class="input-label">Email Address</label>
  <div class="input-container">
    <input type="email" id="email" class="input-field" placeholder="you@example.com">
  </div>
  <div class="input-helper-text">We'll never share your email.</div>
</div>
