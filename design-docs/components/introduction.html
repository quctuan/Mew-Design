Welcome to My VNPT Design System

This documentation acts as the single source of truth for the My VNPT unified design language. It is intended for both designers and developers to maintain consistency across all our digital touchpoints.

Design Principles

  • Clarity: Eliminate ambiguity. Make actions obvious.
  • Consistency: Create familiar experiences by reusing common patterns.
  • Accessibility: Design exclusively inclusive experiences that work for everyone.
