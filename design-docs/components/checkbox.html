Checkbox

Preview

STATES

Props

Name Type Default Description
checked boolean false Tracks whether the item is active/selected.
indeterminate boolean false Used for "Select All" groupings where children have mixed states.
disabled boolean false Prevents state toggling via clicks or keyboard events.

Accessibility

  • Uses visually hidden native <input type="checkbox"> to inherently handle Space key toggling.
  • Requires aria-checked="mixed" exclusively when managing an Indeterminate parent node.
  • Focus ring guarantees visibility mapping to the Brand Primary token for sequential Tab navigation.

Usage

  <input type="checkbox" class="checkbox-input" id="terms">

  </div>

</label>
