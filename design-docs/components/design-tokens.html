Design Tokens

Design tokens are the visual design atoms of the design system — specifically, they are named entities that store visual design attributes. We use them in place of hard-coded values (such as hex values for color or pixel values for spacing) in order to maintain a scalable and consistent visual system.

Colors

Our color system is mapped via CSS Variables located in styles/globals.css. To use a color, reference it like this: var(--1-color-modes-default-background-bg-brand-primary) or var(--1-color-modes-error-text-text-error).

Spacing

All spacings should be determined via the design tokens to ensure vertical and horizontal rhythm.
