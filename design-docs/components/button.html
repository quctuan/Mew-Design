Props

Name Type Default Description
hierarchy "primary" | "secondary" | "tertiary" "primary" Visual variant defining the importance of the button.
size "large" | "medium" | "small" "medium" Size affects height, padding, and font metrics.
disabled boolean false Whether the button is disabled. Prevents interactions.

Accessibility

  • Built on native HTML <button> — full keyboard (Enter/Space) and screen reader support.
  • Focus states use a visible 2px offset solid outline using the system focus token.
  • Color contrast satisfies WCAG 2.1 AA standards for all enabled variants.

Usage

HTML 
<!-- Primary Action -->
<button class="btn btn-primary btn-lg">
  Submit Form
</button>

<!-- Secondary Action -->
<button class="btn btn-secondary btn-md">
  Cancel
</button>
