Props

Name Type Default Description
type "alert" | "bottom-sheet" "alert" Controls the physical layout structure and entry animation axis.
intent "neutral" | "destructive" | "positive" "neutral" Overrides internal text and primary button colors for specific semantics.
isOpen boolean false Hooks to render the portal and background overlay.

Accessibility

  • Focus is programmatically trapped inside the dialog wrapper until it is explicitly dismissed.
  • The role="dialog" and aria-modal="true" identifiers inform screen readers to pause background context.
  • Pressing the Escape key universally triggers the close handler to dismiss the overlay safely.

Usage

HTML 
<!-- Alert Dialog Wrapper -->
<div class="modal-overlay" aria-hidden="false">
  <div class="modal-dialog" role="dialog" aria-modal="true" aria-labelledby="dialog-title">
    <div class="modal-header">
      <h3 id="dialog-title" class="modal-title">Payment Failed</h3>
    </div>
    <div class="modal-body">Your card could not be charged.</div>
    <div class="modal-footer">
      <button class="btn btn-primary">Retry</button>
    </div>
  </div>
</div>
