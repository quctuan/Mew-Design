STANDARD TABS
WITH TAGS / BADGES

Props

Name Type Default Description
active boolean false Controls the visual selection and underline state of the tab.
showTag boolean false Displays a numeric badge or status indicator inside the tab item.

Accessibility

  • The parent container implements role="tablist" to establish semantic boundaries for screen readers.
  • Individual items employ role="tab" and dynamically toggle aria-selected="true/false".
  • Arrow key navigation (Left/Right) shifts focus between tabs without relying on the physical pointer.

Usage

HTML 
<div class="tabs-group" role="tablist">
  <button class="tab-item is-active" role="tab" aria-selected="true">
    General
  </button>
  <button class="tab-item" role="tab" aria-selected="false">
    Messages
    <span class="tab-tag">5</span>
  </button>
</div>
