# Keep design sessions focused

- Read specific Figma nodes, pages, or sections before requesting a whole file. Save large responses to a file and search them when possible.
- Capture screenshots at meaningful visual checkpoints. Use numeric geometry checks for intermediate changes, then inspect the rendered result; measurements alone cannot verify visual quality.
- Send the critic 1x renders unless fine craft requires more detail. After the first round, send the contact sheet and changed screens with the previous asks.
- When a task is done, record decisions in project memory before starting a new session. Resume from those files so the designer does not repeat context.
- Use deterministic checks for mechanical failures. Delegate bounded work only when available and authorized; a separate agent also needs context and has its own usage.

Use the client's measured usage when assessing cost. Avoid fixed screenshot token estimates or assumptions about cache reuse and compaction. Read `model-selection.md` when choosing how to run a role.
